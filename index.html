The RPG Plus Experience

Early game bites back

You start fragile. Every level, every drop, every skill point spent pulls you further from "just surviving" toward something worth telling people about.

  1. Survive

    No hand-holding. The early game is genuinely hard — that's the point.

  2. Gear Up

    Spend earned points on skills that match how you actually play.

  4. Conquer Dungeons

    Take that build into hand-built dungeons and the bosses guarding them.

Included, not optional

Distant Horizons 2.3 & compatible Iris shaders

The pack ships with Distant Horizons already configured, so terrain renders out far past normal view distance, plus Iris shaders picked to work with it out of the box. Want a different shader? Any shader compatible with Distant Horizons will work — you'll just need to add it yourself.

FAQ

Before you ask in Discord

Install the Modrinth Launcher, then download RPG Plus from inside it.

Join the Discord and post in the #help-required thread.

There are 156+ mods to load, and Distant Horizons takes extra time on top of that. Give it a minute — it's normal.

Distant Horizons needs a compatible shader. The included ones already work; if you want another, find one that's Distant Horizons-compatible and add it yourself.

Check your Java memory limit in Modrinth first — the default is low, so raise it based on your available RAM. You can also lower the Distant Horizons and shader settings.

Everything is pulled unmodified from official Modrinth and CurseForge sources — this pack is a curated combination, not altered content.
