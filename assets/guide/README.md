# Guide screenshots

Put guide screenshots here. In `guide.html`, find an `IMAGE SLOT` comment and
replace the following `.guide-media__placeholder` div with an image, for example:

```html
<img src="assets/guide/installation.webp"
     alt="RPG Plus selected in the Modrinth Launcher"
     loading="lazy" width="1280" height="720">
```

Keep the surrounding figure and edit its caption. The image scales automatically.
Slots are provided for installation, controls, character skills, and video settings.
